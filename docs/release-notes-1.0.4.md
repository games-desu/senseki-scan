# v1.0.4（2026-09-07）

https://github.com/games-desu/senseki-scan/releases/tag/v1.0.4

## 改善
- **「CSVをコピー」の手応え**（利用者フィードバック「押しても何も反応がない」）
  - 押したボタンが2.5秒「コピーしました」に変わり、画面下中央に「CSVをコピーしました（N試合）→ SENSEKI FEVER の一括登録ページで『クリップボードから読み込む』」の案内を出す
  - 失敗したときは赤い案内で「CSVを保存」を勧める
  - コピー自体もアプリ本体（メインプロセス）のクリップボードで行うように変更。従来の方式はウィンドウが手前にないと失敗することがあった

## 修正
- **ダブルスで自分のキャサリンが チコ（黒）と読まれる件**（利用者フィードバック）
  - ダブルスの辞書にキャサリンは相手側（オレンジのカード）の手札しか無く、自分側（青のカード）に出ると一番近い別キャラ＝チコ（黒）に化けることがあった
  - 自分側・相手側の両方のキャサリンを収穫して辞書に追加（ダブルス辞書 100→102）。手持ちの録画で自分側 0.78→1.00
