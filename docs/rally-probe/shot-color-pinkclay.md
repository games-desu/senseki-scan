## 打つ前の予兆（チャージ）

t=19.97 で手前のノコノコの足元に**白く光るリング／ディスク**が出ている。
同フレームの実況吹き出しが「チャージのきいたいい感じ!」＝チャージ中であることをゲーム自身が言っている。
→ **打つ前にチャージの有無が分かる**。色サンプリングのトリガとして使える可能性がある。

## 打球エフェクトは「幅の広いビーム」と「細い白煙」の2系統がある（重要）

- **幅の広い色つきビーム**（紫 t=9.60、橙 t=11.25）… 画面を横切る太い帯。彩度が高い
- **細く淡い白煙のトレイル**（t=10.0、t=20.3）… S<0.15 のほぼ無彩色

t=10.0 の白煙の球は相手コート深くまで飛んでおり、t=20.3 の白煙（チャージリングつき）とは
軌道が違う。**「白煙 = ドロップ」と即断せず、無チャージの通常返球でも白煙になる可能性を残す**。
ここは要追加検証。

## この動画で新たに見つかったテキストラベル

- **「GOOD」**（黄緑・コート上・t=8.93〜9.8頃）
- **「Out」**（白・画面中央の暗バンド・t≈3.7〜4.7）
- 既知の「MATCH POINT」「Winner」も出る

### GOOD / NICE / LATE は「サーブのタイミング評価」（ユーザー情報 2026-08-24）

ユーザーより:
- **GOOD・NICE はサーブの時にしか出ない**
- **ボスパックンに限り、サーブのタイミングが遅いと「LATE」が出る**

これを実測で裏取りした（この動画・15fpsと個別フレーム）:

| 時刻 | GOODラベル | 球速ボード |
|---|---|---|
| 8.7 | 無し | 数字なし |
| **8.93** | **出現** | **138 に更新** |
| 9.1 / 9.5 | 継続 | 138 |
| 12.0 / 20.0 | 消灯 | 138（ラリー中ずっと不変） |

→ **GOODの出現と球速ボードの更新が同時**であり、その後ラリー中は値が動かない。
`speed-fever.md` の「球速ボード＝サーブ速度専用」という結論と完全に整合する。

### ただしラベルはサーブ検出の主手段にはならない（ユーザー追加情報・重要な訂正）

ユーザーより追加:
> **GOOD、NICE、LATEでもない場合は、ラベルは表示されないサーブが打ててしまいます**

つまり **「ラベル無しのサーブ」が普通に存在する**。したがって
「GOOD/NICE/LATE の出現 ＝ サーブ」という検出は**取りこぼす**。主手段にしてはいけない。

一方、球速ボードは（サーブ速度専用なので）**全サーブで更新される可能性がある**が、
コートによってボード自体が存在しない。こちらも単独では足りない。

→ サーブ検出は別途調査中（`serve-camera.md` / `serve-labels-rate.md` /
`serve-speedboard.md` / `serve-toss-pose.md`）。
本命候補は **サーブ時のカメラ視点がラリー画と別物になる**という報告（`player-position.md` F2）と、
**トス動作**（コート・UIに一切依存しない）。

### 注意: t=9.60 の紫ビームは「サーブ」だった

上で フラット（紫）として実測した t=9.60 のビームは、t≈8.9 のサーブに続くもの＝**サーブの軌跡**。

ユーザー情報:
> **サーブに関しても、フラット、スライス、トップスピンが選べます！なので、それぞれの色になりますよ**

→ **サーブを色分類の特別扱いにする必要はない。同じ色分類ロジックがそのまま通る。**
t=9.60 の実測値も フラット色の正当なサンプルとして使える。

なお、別動画では1ラリー4秒の中で 青(118.68) → 紫(120.0) → 赤(120.7) → 黄(122.8) と
4色が連続して観測されている（`shot-color.md`）ので、色つきビーム自体はラリー中のストロークにも出る。
「色つきビーム＝サーブ」ではない。
