### ラベルは「サーブを打った側」に出る。自分・相手の両方に出る
- 自分（手前）のサーブ → 手前コートに大きく出る（FHD 文字高 ≈ 55〜60px）
- 相手（奥）のサーブ → **奥コートに小さく出る**（FHD 文字高 ≈ 30〜40px・画面上部 y=130〜210）
- **labels-star.md の「画面上部（y<400）には出なかった」は誤り**。奥コートのサーブラベルは
  FHD y = 130〜215 に出る（実測 22-02-04 @79.5 で y≈132〜175）。
  奥コートを見ないと**相手サーブのラベルを全部取りこぼす**。

### 出現タイミング = サーブのインパクトと同一フレーム
- 自分サーブ: サーブカメラ→ラリーカメラの**ハードカット**と**同一フレーム**でラベルが出る（実測 20件すべて）。
- 相手サーブ: カメラは切り替わらない（ラリーカメラのまま）。ラベルはインパクトと同時。
- 持続 **0.8〜1.3秒**（10fpsサンプルで 8〜13フレーム）。

| 語 | 塗り | 実測 |

**訂正**: labels-star.md は NICE を「橙→赤のグラデ」としているが、実測は **橙→黄→黄緑**（右端は GOOD と同じ黄緑）。
赤は入っていない。→ **色相ヒストだけで GOOD/NICE を分けるなら「左端の色相」を見ること**
（NICE は 0〜30°帯を持つ、GOOD は 60°帯のみ）。

### 同時に出る他のもの（実測）
- **球速ボード**（3Dオブジェクト・コートによって有無あり）がサーブ速度に更新される。
  22-02-04 で実測: 147 / 174 / 178 / 187 / 201 / 202 / 237 km/h。
- サーブの**カラートレイル**（紫＝フラット / 青＝スライス / 橙＝トップスピン）がラベルと同時に出る。
- 自分サーブでは**サーブカメラ**（低い位置・空が上半分・sky指標 0.43〜0.65）から
  **ラリーカメラ**（空ほぼ無し・sky 0.02〜0.07）へハードカット。**これが最も強いサーブ信号**（下記）。
