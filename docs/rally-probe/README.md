## 既知の訂正

- `shot-color.md` の D項・L1項・L2項の時間解釈に誤りがある（`charge-lifecycle.md` §5 に訂正表）。
  白い4条星は打点マーカーではなく、打点の 0.03〜0.32秒**前**に出るチャージ完了の合図。
- `court-robustness.md` のピップ中心x（33,58,83…）は14pxずれている。
  正しくは 46.5+25k（`deuce-pips.md` が正しい。実測で決着済み）。
- `court-robustness.md` の「カメラは0.2秒で3px以下」はラリー静止時の値。
  ラリー中のドリーは最大5px/frame（`impact-effects.md`）。
