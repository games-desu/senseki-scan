# 球速ボードでサーブを検出できるか（作業中・随時上書き）

最終更新 2026-08-24。担当: 球速ボード。**途中経過。末尾に確定分をまとめる。**

## 現時点の判定（暫定）

**球速ボードは「サーブの瞬間」の指標として極めて強い。**
理由: **ポイント境界でボードは必ず「空白（数字なし）」にリセットされ、サーブの打球音と同時に数字が出る。**
「数字が変わった」ではなく **「空白 → 数字」** が本命の遷移。差分が桁違い（白画素 0〜20 → 300〜550）で閾値が要らないレベル。

`2026-08-20 11-33-43.mp4`（芝・FHD）240〜350秒 = **9ポイント中 9件検出（9/9）**。

## 検出アルゴリズム（実装できる粒度・実測でチューニング済み）

### ボードの探索（固定ROI不可・3Dオブジェクト）

```js
// 入力: 1920x1080 に正規化した RGB フレーム（720p/1440p 素材も一旦 FHD へスケール）
// 1) 「ほぼ純黒」画素の連結成分を取る
const isDark = (r,g,b) => lum(r,g,b) < 34 && (max(r,g,b)-min(r,g,b)) < 30;
//    探索帯: y < H*0.62（ボードは常に地平線より上。コート面や影を拾わないため）
// 2) 形状フィルタ
//    w 30..320 / h 18..200 / アスペクト w/h 0.9..3.2 / bbox内の黒率 >= 0.55
// 3) 黄枠リング判定: bbox を w,h の 22% 外へ広げたリング（bbox内は除外）で
const isYellow = (r,g,b) => { const mx=max(r,g,b), mn=min(r,g,b);
  return mx>70 && (mx-mn)>0.42*mx && b===mn && Math.abs(r-g)<0.45*mx && g>0.45*mx; };
//    リング内 isYellow 率 >= 0.45 を要求（実測: 本物 0.56〜0.83／偽 0.00〜0.35）
// 4) 複数候補が残ったら yellow率 * sqrt(黒画素数) の最大を採用
```
**重要: 黄枠は日陰で暗くなる**（ピンククレイ実測 rgb(135,128,12)＝輝度120程度）。
`r>150` のような絶対閾値は通らない。**`b` が最小・`r≈g`・彩度は max に対する比**で判定すること。

### 数字の在否

```js
// bbox 内の白画素数 wn
const isGlyph = (r,g,b) => lum(r,g,b) > 130 && (max(r,g,b)-min(r,g,b)) < 45;
// 実測: 空白 wn = 0〜35 ／ 数字あり wn = 145〜554
// 閾値: BLANK < 40 / NUM > 120
```
数字の実測色は **rgb(186,186,186) 程度**（純白 255 ではない）。`>210` の既存 fillink 述語では落ちる。

### サーブ時刻

```
1) Phase A で得たポイント境界（HUD 2.4〜2.6秒消灯）の「HUD復帰時刻 ret」を取る
2) t in [ret, ret+18] を 20fps で走査し、毎フレーム board = detect(frame)
3) serveT = 最初に board.wn > 120 となった t
   直前の観測が board.wn < 40 なら [tPrevBlank, serveT] が誤差区間（実測 0.05秒＝1サンプル）
```
**「数字が変わった」ではなく「HUD復帰後に初めて数字が見えた時刻」**を使うのが正解。
理由: ボードは復帰時に必ず空白なので、復帰後に数字が見えた＝もうサーブは済んでいる。
ラリー途中でボードが画面外→画面内に戻っても、それは serveT より後なので影響しない。

## 落とし穴（現時点）

1. **ボードは画面外に出る**。`11-33-43` のラリー中の検出率は 58〜214/108〜300 フレーム（55〜93%）。
   サーブ前に一度もボードが見えないポイントがある（341.40 のケース）。
2. **「見失い → 数字あり」を遷移として採ってはいけない**。ラリー中にボードが画面内へ戻ると
   前の値を表示したままなので偽のサーブになる（`11-33-43` 260.6 のポイントで 268.9 に再出現）。
   → 必ず **「HUD復帰後 最初の数字」** に限定する。
3. 数字は **純白ではない（約186）**。既存 fillink の `輝度>215` では読めない。
