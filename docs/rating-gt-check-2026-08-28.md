# レート読み・勝敗帰属のGT修正 — FHD実戦（2026-08-28実施）

素材 = `samples/2026-08-26 23-59-40.mp4`（ユーザー報告のスクショ付き）。
正解 = SENSEKI FEVER DBの12試合・レート24値（ユーザーが誤登録を修正済みの最新値）。

## 判明した問題と対処

### 1. 勝敗・スコアの無警告反転（m1: 実際4-7 lossを7-4 winと出力）【最重要・修正済み】
勝敗パネルの行アイコンが辞書未収穫（キャサリン→デイジー@0.78・ベビィワリオ→クリボー@0.69）で
どちらの行も自キャラに一致せず、**「照合スコアが低い方=自分でない」の当て推量フォールバックが逆を引いた**。
→ ①キャサリン/ベビィワリオのpanelIcons収穫（76→80・照合@1.00確認）
　 ②当て推量フォールバックを廃止し**ミラー戦扱い**（レート増減で確定・不能ならresult/スコアをフラグ）

### 2. レート誤読の連鎖汚染（m6: 3,389→「3189」@0.71が安定ラン化 → m7のレート前に[自動補正]で伝播）【修正済み】
劣化フレームでグリフが痩せ「3」が「1」@0.70にマッチ。正読は0.83以上に分布するため、
**受理confを0.70→0.75に引き上げ**て遮断（vision.js readRatingPair）。
誤読していた0.70-0.71帯は棄却→空欄+フラグになる（誤値が入るより安全）。

### 3. レート変動前が読めない（m1: 3,352 / m6: 3,389 等）【原因特定・読み取り拡大は次段】
同一グラブ検証で確定した原因: **数字間のアンチエイリアスの橋渡しで連結成分が融合**（「352」が1成分化）＋
**segmentCCの縦3pxエロージョンで細ストローク（5・7等）が脱落**。パネルのピンク照明で悪化する。
試した代替と結果:
- 2x拡大(スムージング有/NN): 一部改善するが照合conf崩壊・別フレームで逆に悪化
- 2x分割+等倍照合ハイブリッド: healthyフレームが劣化(3317→2317)
- エロージョンなしCC+谷分割: 分割位置の曖昧さ（橋=colSum5-6 vs 数字内の谷=5-6）で不安定
- 固定セル案: 数字はプロポーショナル幅（「1」が細い）でセル位置が最大7pxずれ不成立
→ **次段の設計**: 右揃えアンカー＋桁ピッチモデル（右端から4桁+カンマの構造でセルを動的推定）か、
　 劣化変種グリフの追加収穫。当面は「変動前=フラグ付き空欄→証拠画像を見て手入力」で安全側。

### 4. VSクロップのステイルフレーム防御を追加【訂正あり】
当初「パトカーふんさい」をギミック演出と誤認したが、**実際は相手プレイヤーの名前**であり
名前の自動入力は正常動作だった（ユーザー指摘 2026-08-28）。追加した「VSクロップ前の
classify==='vs'検証（違えば+0.3sへ再シーク）」は一般的なステイルフレーム防御として存置。

## 追記: 砂コートでの全滅バグ（同日発見→修正・GT検証済み）

ユーザー報告: `2026-08-20 10-44-35.mp4`（720p・アカデミー サンド・classic_singles 3試合）が
mode誤り/スコアnull/レートnullでほぼ全滅。

### 原因（2つ）
1. **明るく低彩度な砂コートの試合中フレームが classify='rating' に大量誤検出**され、
   vs直後の偽レート窓が試合構造を破壊（レート証拠画像がコートの絵になっていたのはこれ）
2. 試合中の黄色の誤検出で**偽winner窓が先に掴まれ、本物（レートパネル直前）が無視**される

### 対策
1. **レートパネル検証ゲート**: rating窓は部門ボード（mode1=シングルス/ダブルス）照合0.85以上のみ採用
   （実測: 本物=1.00 / 砂の誤検出=0.60〜0.70。mode2は砂で0.85が出るため判定にはmode1のみ使用）
2. **groupMatches**: winnerはratingが来るまで最後のもので上書き（本物の勝敗パネルは必ずレートパネル直前）
