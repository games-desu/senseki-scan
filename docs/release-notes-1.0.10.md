# SENSEKI SCAN v1.0.10 リリースノート（詳細版）

2026-09-21。ハイライト生成の改善2点（開発者自身のダブルス録画 2026-09-21 04-08-15 のダイジェストで気づいたもの）。戦績の抽出（CSV）には手を入れていない。

## 1. ダブルスの「自分のキャラを表示」でキャラの顔が切れていた（修正）

### 症状
ダイジェスト冒頭の「自分：」バッジで、パタパタの顔が半分しか写らない。キャサリンだと顔がまったく写らない。

### 原因
ダブルスのVS画面のアイコン枠（118x64）は「キャラが右寄りに入る」と決め打ちして、右端の正方形（x50〜118）を切り抜いていた。
実際の6試合を測ると顔は枠の左寄り〜中央にある（パタパタ x28〜77・キャサリン 0〜55・クリボー 15〜100・マリオ 20〜90・ヨッシー 10〜95）。右端の約20pxはラケットや羽だけ。

### 修正
左端の約12px（ランク表示 S+/S- が食い込む部分）だけ外して、x12〜112 の 100x64 を使う。シングルスは変えていない。

## 2. 「この試合は誰との対戦か」を一覧とファイル名で分かるように（新機能）

ハイライトは X などに投稿する前提でプレイヤー名を動画に映さない作りだが、そのぶん保存したあとで「この試合は誰とだったか」が分からなかった。

- 一覧の各試合の見出しの下に **VS画面のカード（名前とキャラ）** をそのまま出す。読み取りに頼らないので必ず出る
- あわせて読めた名前を「相手: ○○・△△　味方: □□」と出す。名前の読み取りは戦績の抽出と同じ2段（確定済みの名前画像との照合 → 文字辞書）なので、
  戦績CSVで一度確定した相手は次から読める。読めなかった人はキャラ名に「(キャラ)」を添えて区別する。同じ録画を戦績CSVで先に解析していれば、そこで直した名前を優先する
- ファイル名に `_vs相手名` を入れる（`録画名_試合2_vs○○・△△_ダイジェスト.mp4`）。読めた名前だけを使い、読めない相手は入れない（キャラ名では代用しない）。
  「ファイル名に相手の名前を入れる」チェック（既定ON）で外せる。**動画そのものには従来どおり名前は入らない**
- 区間調整の見出しにも「vs 相手名」を出す

## 未対応（要望として記録）

ダブルスで「自分と味方のどちらが決めたポイントか」（相手側も同様）の表示。画面のどこにもその情報が出ない（HUD・ポイント間バナー・ジュゲムの吹き出し・得点直後のカメラのいずれにも印が無い）ため、
「勝った側で最後に打った人」をラリー解析（ボール追跡）で取る必要があり、いまの精度では出せない。詳細は docs/highlight.md。
