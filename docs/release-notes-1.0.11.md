# SENSEKI SCAN v1.0.11 リリースノート（詳細版）

2026-09-22。米国の利用者 AuntStarr さんから「英語版のゲーム画面の録画を読み込むとエラーになる」と報告があり、
提供された録画2本（720p30・OBS・いずれも1試合）で原因を特定して直した。日本語の録画の読み取りは変えていない。

## 症状と原因

英語版の録画は、VS画面・勝敗パネル・レートパネルの**検出**まではすべて日本語版と同じに通るのに、最後に**必ず0試合**になる。
ログでは次の2行が出ていた（利用者にはこれが「エラー」に見えた）。

```
[警告] 部門ボード照合が低いレート窓を1件棄却しました(101秒)。…
[警告] VS画面1回に対し成立した試合が0件です。…
```

原因は**レートパネルの「部門ボード」が英語**なこと。本物のレートパネルかどうかを、パネル左上の「シングルス／ダブルス」の
文字を画像テンプレで照合して判定している（砂コートの試合中フレームがレートパネルに誤検出される件の対策・0.85 以上で採用）。
英語の "Singles" は日本語の手札と **0.52** しか一致せず（ダブルス0.52・シングルス0.52＝どちらにも似ていない）、
レート窓が丸ごと棄却され、レートの無い試合は成立しないので0試合になっていた。

同じ理由で、英語だと **フィーバーラケット あり/なし**（"No Fever Rackets"＝0.76）と**コート名**（"Academy Court (Brick)"＝0.57）も
辞書と一致しない。一方、キャラのアイコン（ボスパックン0.989・デイジー0.996）、レートの数字（"5,356"・カンマ区切りも日本語と同じ字形）、
勝敗パネルの数字、回線アイコンは言語に依存せず、そのまま読めていた。

**解像度（720p）は原因ではない**。利用者は「[注意] ゲーム画面の横幅が 1280px で、フルHD の8割未満です」の表示から
解像度を疑っていたが、これは注意喚起であって棄却ではない。ただし 720p ではレートの数字が小さく、
読み取りが緩和モードになって「要確認」が付く（今回の2本とも値は正しく 5356→5357 と読めたが、レート前後に要確認が付いた）。
1080p で録画すれば要確認は減る。

## 修正

1. **英語の手札を同梱辞書に追加**（ラベルは日本語のまま）: 部門ボード "Singles"→シングルス（2枚）、
   "No Fever Rackets"→なし（2枚）、コート名 "Academy Court (Brick)"→アカデミー ブロック、"Stadium Court (Grass)"→スタジアム グラス。
   照合はライブラリ内の最大スコアを取るだけなので、判定コードはそのまま動く。
   日本語の反対ラベルとの最大一致は 0.52（部門）/0.77（ラケット）/0.72（コート）で、日本語の録画には影響しない。
   手札は S+（ピンクのパネル）で採ったもの。別ランク色のパネルは未検証（日本語も同じ制約）。
2. **なし/あり の片側しか手札が無い見た目では要確認にする**: なし/あり の手札は文字が小さくパネルの地が支配的で、
   反対ラベル同士でも 0.99 で並ぶ（同梱の日本語辞書で実測）。英語は "With Fever Rackets" が未収穫なので、
   フィーバーの試合が "No Fever Rackets"＝クラシックに黙って化ける。勝った手札と 0.9 以上で並ぶ反対ラベルの手札が
   辞書に無いときは部門を要確認にする（反対側が揃えば自動で外れる。日本語の録画では従来どおり付かない）。
3. **部門（mode）の教えるサイクル**: 部門を手で直して確定したとき、読み違えていた側（シングルス/ダブルス・なし/あり）の
   画像を修正後のラベルで利用者の辞書に足す。キャラ・コートと同じ仕組み。英語の "With Fever Rackets" や未収穫のランク色を
   利用者の手元で育てられる。

## 検証

- 提供録画2本: 0試合 → それぞれ1試合。`classic_singles ボスパックン vs デイジー 7-0 win →5356 @アカデミー ブロック`／
  `classic_singles ボスパックン vs ドンキーコング 7-5 win 5356→5357 @スタジアム グラス`＝画面と一致（要確認: 部門＝上記2・レート前後＝720p）
- 日本語の回帰7本（クラシックシングルス4試合／クラシックダブルス5試合／フィーバーシングルス1試合／フィーバーダブルス2試合／
  配信レイアウト720p 1試合／ほか2本）: 修正前後で CSV・要確認・警告ログが完全一致。砂コート対策の棄却も従来どおり働く
- 教えるサイクル: classic→fever に直すと なし の手札は増えず あり が1枚、さらに doubles に直すと ダブルス が1枚（重複は増えない）

## まだ対応していないもの（英語版）

- **ダブルス**（"Doubles" の手札が無い＝部門ボードの照合を通らず、従来どおり0試合になる）
- **フィーバーラケットあり**（"With Fever Rackets"。読めるが部門が要確認になる。手で直せば以後は自分の辞書で読める）
- コート名 14種（読めた試合は出るが、コートが要確認になる。直せば以後は自分の辞書で読める）
- ラケット名のバナー30種（フィーバーのみ。未照合の要確認）
- アプリの画面（日本語UI）の英語化

英語のダブルス・フィーバーの録画が1本ずつあれば同梱辞書に足せる。
