# Mario Tennis Fever ゲーム仕様（ユーザー提供）

映像解析の設計はここに書かれた仕様に従うこと。**すべてユーザー（実プレイヤー）から直接提供された情報**であり、
映像から推測したものではない。実測で食い違ったらユーザーに確認する。

## ショットの種類

| 種別 | 色 |
|---|---|
| トップスピン | 赤 |
| スライス | 青 |
| フラット | 紫 |
| ロブ | 黄っぽい |
| ドロップ | 白っぽい |

- **サーブでもフラット/スライス/トップスピンが選べ、それぞれの色になる**（2026-08-25）
  → 色分類においてサーブを特別扱いする必要はない。同じロジックがそのまま通る。
- 各ショットは**チャージ可能**。最大まで溜めると**マックスチャージショット**。
- ショットボタン**2回押し＝強打**（角度はつかないが速い）。**1回押し＝弱打**（遅いが角度がつく）。
  ユーザーの呼称は「きょうだ」「じゃくだ」。
- バウンド後に打つ＝**ストローク** / バウンド前に打つ＝**ボレー**。
- フィーバーゲージを1個消費（最大2ストック）で**フィーバーラケット固有のショット**。
  発動時にラケット名のバナーが出る（`docs/rackets.md` の31種）。

### ユーザー指定の解析スコープ（2026-08-25）

**判別が必要なのは6種だけ**: ロブ / ドロップ / トップスピン / スライス / フラット / フィーバーショット。
**ボレーとストロークの判別、強打と弱打の判別は不要**。

## チャージの挙動（★2026-08-25・設計に効く）

- **マックスチャージが完了すると白い閃光が出る**。これは「溜まりきった」ことを示す合図であり、
  **打点のインパクトエフェクトではない**。打つより**前**に、打つ側の選手のところに出る。
- **チャージはキャンセルできる**。閃光が出たあとキャンセルして、普通のショットに切り替えられる。
  → **「白い閃光を検出した＝マックスチャージショットが打たれた」は誤り。**
- 実例: `samples/2026-08-20 10-44-35.mp4` の 386.0〜388.2秒。
  ゲッソーがマックスチャージ完了の閃光を出したあと、**キャンセルして普通のドロップショット**を打っている。

## とびつきショット（★2026-08-25・設計に効く）

- 遠い球に**とびついて**返した場合、**ショットのエフェクトが出ない**。
- → **「打点エフェクトの有無」だけで打点を判定する方式は、とびつきを取りこぼす。** 必ずフォールバックを用意する。
- 実例: 上と同じクリップ。387.23秒のバウンドに対してハナチャンがとびついて返している。

## サーブのタイミング評価ラベル

- **GOOD / NICE はサーブの時にしか出ない。**
- **ボスパックンに限り**、サーブのタイミングが遅いと **LATE** が出る。
- **ただし、GOOD・NICE・LATE のどれも出ないサーブが普通に打てる**（2026-08-25）。
  → **ラベルだけに頼るサーブ検出は取りこぼす。主手段にしてはいけない。**

## 着弾マーカー（星）

- 地面に出る黄色い星型マーカーは**常に出るわけではない**。
  **ロブや弾道が高くなったショットに対して出やすい**。
- → 着弾点の検出をこのマーカーに依存させてはいけない。

## 球速ボード

- コート内の3D看板に球速が出るが、**コートによって有ったり無かったりする**。
- **サーブ速度専用**（実測で確定。ラリー中の10球で値が一切変化しないことを確認）。
- → 強打/弱打やチャージ段階の判別には使えない。

## 得点表示

- 1試合＝7ポイント先取。**デュースあり**（8点以上になる。実例 8-6）。
- 通常は画面下左右に大きな数字＋**テニスボール型のピップ7個**。
- **デュースになるとピップが7個から中央寄せ2個に変わる**（残りは斜めストライプ塗り）。
- アドバンテージ側は数字が「**Adv.**」に置き換わり、2スロットの左だけ点灯。
- → ポイント境界を「点灯ピップ数の増加」で取ると**必ず壊れる**。
  実装は HUD の消灯区間（約2.4〜2.6秒）で取っている（`tools/rally.js`）。

## その他の画面ラベル

実測で確認したもの: `SMASH!` / `Body Shot` / `Change Court` / `Out` / `GOOD` / `NICE` / `Winner` /
`MATCH POINT` / フィーバーショット名（`ドロドロショット` 等＝ラケットバナー）。

## 映像制作上の注意

- **編集ソフトで再エンコードした動画は使わない**。カット欠損で勝敗画面が消え、画質劣化でレートの桁落ちが起きる。
  OBS等の元録画を使うこと。
- 録画の解像度は混在する（1280x720 / 1920x1080 / 2560x1440・いずれも60fps）。
  ユーザー提供のスマホ書き出し（1920x1080 **30fps**）もある。座標は必ずFHD換算で持つこと。
