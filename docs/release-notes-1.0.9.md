# SENSEKI SCAN v1.0.9 リリースノート（詳細版）

2026-09-10。v1.0.8 を試してもらった利用者（ぴんやさん）からの再報告。素材は前回と同じ切り出し
（`20260909_4_10.mp4`・5分17秒・1920x1080・ゲーム画面 1404x789）。

報告は3点あったが、**確実な不具合は1点だけ**で、残り2点は「判定が紙一重で環境によって反転する」種類のものだった。
分けて書く。

## 1. 画面から読めたレートを、連鎖補完が上書きしていた（修正）

### 症状
解析ログには `m2: ... R3207→3213` と出ているのに、CSVでは `rating_before=3174` になる。
つまり**画面から正しく読めた値が、出力では別の値に化けていた**。

### 原因
後段の「レート連鎖検証」が、要確認フラグの立っている変動前を**無条件に前試合の変動後で差し替えて**いた。

```js
} else if (cur.ratingBefore == null || cur.flags.ratingBefore) {
  cur.ratingBefore = prev.ratingAfter;   // ← 画面読みがあっても上書き
}
```

今回の m2 の画面読みは **3207・確信度 0.777・安定** と十分だったが、要確認ライン 0.8 をわずかに下回っていたため
上書きの対象になっていた。

さらに根本として、**この動画では連鎖がそもそも成り立たない**。元の配信から m4 と m10 だけを切り出したもので、
2試合は連続していないからである。連鎖は「動画内の試合が連続している」という**前提つきの推測**にすぎず、
切り出し動画・録画外で挟んだ試合・取り逃した試合では破綻する。

### 修正
画面がしっかり読めている（`stable` かつ確信度 0.75 以上）のに連鎖と食い違うときは、
**画面の値を残し、両方を要確認にする**。直接の証拠を、前提つきの推測で消さない、という方針に統一した。

```
m2: 画面のレート前(3207)と前試合のafter(3163)が違います。画面の値を残しました（連続した試合でないか、どちらかの読み違いです）
```

連続した録画ではこれまでどおり連鎖で埋まる（挙動は変えていない）。

## 2. ゲーム画面が小さい録画の案内を追加

レートの4桁は文字が小さく、ゲーム画面が縮むほど読み取りの確信度が落ちる。今回の録画は
**フルHDの73%（1404px）**で、4つの読み取りの確信度が 0.617 / 0.626 / 0.777 / 0.625 と、
受理ライン 0.60 のすぐ上に密集していた。数フレーム落ちるだけで読めなくなる状態である。

**受理ラインは緩めていない**（誤読を招くため）。代わりに、小さい録画では最初に案内を出すようにした。

```
[注意] ゲーム画面の横幅が 1404px で、フルHD(1920px)の8割未満です。レートの数字が小さくなり、
       読み取りの確信度が下がります（要確認が増えます）。配信レイアウトごと録るより、
       ゲーム画面を大きく録るほうが安定します。
```

従来の警告は「横1280px未満」だけで、1404px は素通りしていた。

## 3. 直っていない件（ヘイホーの色・v1.0.8 の積み残し）

報告のうち「ヘイホーが赤ではなくピンクになる」「1試合目のレートが読めない」の2点は、
**こちらの手元では正しく出る**（`3174→3163` ／ 相手は無印＝赤）。同じ動画・同じ版でも結果が分かれた。

切り分けた結果、**判定の余裕が無いことが原因**だった。

| | 値 | 余裕 |
|---|---|---|
| 相手ヘイホーの色 | 無印 0.8532 / ピンク 0.8496 | **0.0036** |
| レートの確信度 | 0.617 / 0.626 / 0.777 / 0.625（受理 0.60） | わずか |

この幅は、動画のデコードがわずかに違うだけで超える。潰した候補は
**GPUデコードの有無・Chromium の版（system Chrome 152 と、アプリ同梱 Electron 38＝Chromium 140 の両方）・
ユーザー辞書・ゲーム画面の位置**で、いずれも影響なし。**同一環境での再実行は決定的**（2回とも完全一致）なので、
毎回変わるわけではない。

対策の方向は「正しい側に倒す」ではなく**余裕を広げる**か**僅差を要確認にする**かで、これは次の課題とする。
なお同じ試合でも**自分側**は ピンク 0.8873 / 無印 0.7240 と差 0.16 で盤石であり、揺れるのは相手側の1枚だけ。
実害は色違い1項目の手直しで済む。

**色が違っていたときは直してほしい。** 手で直した値はユーザー辞書に取り込まれ、次回から自動で当たるようになる
（認識が当たっていた値は取り込まないので、直さなければ辞書は汚れない）。
