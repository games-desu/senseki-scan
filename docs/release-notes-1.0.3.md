# v1.0.3（2026-09-06）

https://github.com/games-desu/senseki-scan/releases/tag/v1.0.3

## 修正
- **自分側のキャラが大きい（ブンブン・クッパ など）と対戦カード（VS画面）を見逃し、試合がまるごと消える件を修正**
  - VS画面の判定は「自分カードの青・相手カードのオレンジ・中央の白いVSロゴ」の3条件だったが、体の大きいキャラのアイコンが青カードをほぼ全部覆うと青が0になり不成立だった
  - 相手側には以前から「アイコンで隠れても左右の黒い名前帯があれば成立」の救済があったので、自分側にも同じ救済を追加
  - 手持ちの録画9本（約5,000フレーム）で誤検出ゼロを確認。見逃していた2試合（利用者のブンブン戦・開発者のクッパ戦）が拾えるようになった
- ファイル名が `2026年09月04日11時59分.mp4` のような和文形式でも録画の開始日時を読むように（要確認が付かなくなる）

## 開発向け
- `node tools/headless-analyze.js <video> [--rect x,y,w,h] [--debug]`: headless Chrome で本番の画面をそのまま動かし、解析ログ・CSV・要確認フラグを出力する。
  利用者から届いた録画の「検出できない」再現に使う（今回の報告と同一ログを再現できた）
