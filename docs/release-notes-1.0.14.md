# v1.0.14（2026-11-02）：起動時のウィンドウ位置を覚える

## 要望
利用者から（2026-11-01 X DM）: マリオテニスのプレイ中はメインモニターを Switch(HDMI) に切り替えているため、毎回サブモニターへ移動させている。最後に開いていたモニターで起動してほしい。

## 原因
`createWindow`（app/main.js）が width/height だけを指定し位置を渡していなかったため、置き場所は Windows 任せ＝毎回メインモニターに出ていた。

## 修正
- 閉じるときに `getNormalBounds()` と `isMaximized()` を `userData/window-state.json`（key ごと）へ保存し、次回の生成時に使う
- 保存位置のタイトルバー（上端 40px）がどのモニターの作業領域にも 100x20 以上かからなければ保存値を捨て、従来どおり（メインモニター・最大化なし）で開く
- 拡大率の違うモニターでは生成時の x/y/width/height だとサイズが縮む（1360→907 を実測）ため、生成後に `setBounds` し直す
- このリリースは v1.0.13 に上記だけを載せたもの。main にある未リリースのラリー解析（アプリ内）は含まない

## 検証（開発版・メイン 1920x1152 ＋ サブ 2560x1392 の2画面）
- 記録なし → メインモニター（従来と同じ）
- サブモニターで閉じる → 同じ位置・大きさ（2回くり返しても不変）
- サブモニターで最大化して閉じる → サブモニターで最大化
- 画面外の記録／サブモニターを無効にして起動 → メインモニター・最大化なし（開発者の実機でも確認）
