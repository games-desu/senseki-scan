## 実装メモ

- 検出: bannerBand(FHD y690-1010)の純白グリフ塊（幅280+・高さ32-110・高彩度リボン隣接）
- 照合: **列プロファイルの1次元相互相関**（バナーは横スライドし続けるため平行移動不変が必須。同一=0.98-1.00 / 異種=0.5-0.75 / 閾値0.85）
- 帰属: バナー前後のFVゲージ(fvL/fvR)減少量（drop≥0.15かつ差≥0.08。ブーストは減りが緩やかなので後方サンプルは+4秒まで）
- 辞書収穫: DBのラケット登録をGTに、ゲージ帰属した側のラベルで自動収穫（harvest fever set: myRacket/oppRacket）
- 未知バナー: 低スコア→要確認フラグ＋バナー画像をレビューUIに表示（ユーザーが上表から選ぶ→動画ごとに辞書が育つ）
- カタログ動画(00-49-49)は各ラケットのショット演出は映るが**バナー文字は出ない**ため辞書化には未使用（キャプション文字は別フォント）
