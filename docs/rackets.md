## 実装メモ

- 検出: bannerBand(FHD y690-1010)の純白グリフ塊（幅280+・高さ32-110・リボン帯が下に隣接）
- 照合: **列プロファイルの1次元相互相関**（バナーは横スライドし続けるため平行移動不変が必須。同一=0.98-1.00 / 異種=0.5-0.75 / 閾値0.85）
- 帰属: FVゲージ時系列のエッジ検出（2026-08-29刷新・2026-09-05改良）。領域 fvL/fvR は「ストック枡＋充填バー」を左右対称に含む（旧値は左がバーだけで自分の発動＝枡の消灯が読めなかった）。HUD可視ゲートは「枡とバーの境目の黒い縦罫が両側とも暗い」こと（旧・回線アイコンは回線1〜2本で点滅して落ちる）。エッジ＝直前2点minから0.18以上の急落・落下先0.45以下・次点があれば低いまま
- 辞書収穫: DBのラケット登録をGTに、ゲージ帰属した側のラベルで自動収穫（harvest fever set: myRacket/oppRacket）
- 未知バナー: 低スコア→要確認フラグ＋バナー画像をレビューUIに表示（ユーザーが上表から選ぶ→動画ごとに辞書が育つ）
- バナーは斜め表示の種類がある（メタルブースト実測: 文字ボックス高131px@FHD）→ collectBanners は maxH160 で探索（2026-08-27）
- 試合中の相手ネームプレート表示（黒帯の名前テキスト）が findBanner を通過して低スコアイベントになる → score<0.7 はフラグ根拠にしない（詳細 docs/racket-gt-check-fhd-2026-08-27.md）
- カタログ動画(00-49-49)は各ラケットのショット演出は映るが**バナー文字は出ない**ため辞書化には未使用（キャプション文字は別フォント）
- **リボンの色はショットごとに違う（ファイアバー=橙／マジック=青紫／ドッスン=灰／ドロドロ=茶）。
  「高彩度リボン」条件は灰・茶のラケットを丸ごと落としていた**（2026-08-31判明・ユーザー指摘）。
  実測: 色リボン sat 0.44〜0.77 / 帯の輝度sd 57〜91、灰リボン(ドッスン) **sat 0.000** / sd 47.3。
  → findBanner のリボン判定を「高彩度 **または** 帯の輝度sd>=35 かつ 文字幅>=660」に緩和(2026-08-31)。
  低彩度側の誤検出はワルイージピンボールの得点演出メダル「Mario Tennis Fever」(幅475〜558)で、
  本物のバナーは最短でも幅701(7文字名)なので幅660で分離できる。
  **ランクマ素材(2026-08-30 01-44-03・30分)で通過イベント28件が前後で完全に不変**＝退行なし。
  同素材のオフライン録画では検出0件→4件(ドロドロ2/ドッスン2)に増えた
- 「ドッスンは前回、画面端で見切れて収穫失敗」と記録していたのは**誤診**で、正体はこの灰リボン棄却だった
- オフライン録画は回線アイコンが出ないため旧ゲートでは side帰属不可だった。2026-09-05 のゲージ枠ゲートなら通る見込み（未検証）
  （辞書収穫は目視ラベルなので支障なし）
