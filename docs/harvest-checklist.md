# 辞書収穫用の録画チェックリスト（2026-08-30版）

ランクマッチ以外（フレンド戦・COM戦等）で辞書の未収穫を埋めるための録画リスト。
**録画設定はいつも通り（1080p・60fps・6〜12Mbps・OBS元録画）**。複数試合を1本にまとめてOK。
撮れたら samples/ に入れて「収穫用」と伝えてください。ラベルは映像から目視確定するので、
**SENSEKI FEVERへの登録は不要**です。

**運用**: 収穫が終わるたびにClaudeがこのファイルのチェックを更新してコミットします。
進み具合は https://github.com/games-desu/senseki-scan/blob/main/docs/harvest-checklist.md でいつでも確認できます。

### パイロットの結果（2026-08-31）

素材: アカデミー クレイ／ベビィピーチ vs ベビィワルイージ（7ポイントマッチ・COM戦）

| 項目 | 判定 | 実測 |
|---|---|---|
| VS画面 | **ランクマと同一** | classify=vs／コート「アカデミー クレイ」0.984／相手アイコン ベビィワルイージ 0.963（どちらもランクマ由来の辞書とそのまま一致） |
| 勝敗パネル | **ランクマと同一** | locateWinner成立(t=144.75/row1)・パネルアイコン ベビィワルイージ 0.944・勝者スコア7をconf1.00で読了 |
| レートパネル | 無し（想定通り） | 試合としては0件になる＝**アプリのUIには出ない**。収穫は目視ラベルで行うので支障なし |
| 回線アイコン | 無し（オフラインのため） | HUD可視ゲートが常にfalse → FVゲージの時系列が取れず**side帰属(自分/相手)は不可**。目視ラベルなので支障なし |
| **ラケット発動バナー** | **形式が違う → 拾えない** | 下記 |

**ラケットだけ形式が違う**: オフラインでは発動時にカットイン演出が入り、
ショット名が「**黒帯に白文字のキャプション**」として横スライドする。ランクマの
「**色リボン付きバナー**」ではないため、findBanner のリボン条件で落ちて**1件も検出されない**
（実測 ribbon=0.000／darkIn=0.43／幅1034px・高さ90px）。この動画の「ドッスンショット」も未検出。

ただし**文字の書体・大きさ・スライドの仕方はランクマのバナーと同じ寸法帯**（辞書の既存プロファイルも
幅700〜1100が中心）で、既存19種との照合スコアも0.88＝「未収穫ラケットの典型値」に収まる。
→ **収穫プローブ側でリボン条件を外せば収穫できる見込み**（アプリ本体は変更しないので誤検出リスクは無い）。
確証を取るため次の対照録画をお願いします。

## 0.5 対照録画（2分・**次はこれ**）

- [ ] **すでに収穫済みのラケット**（`トゲゾー` / `カーブ` / `たつまき` / `フリーズ` のどれか1本）を装備して、
      同じオフライン対戦で**発動2〜3回**。試合は途中でやめてOK
- → キャプションから作ったプロファイルがランクマ由来の辞書と**0.93以上で一致すれば**、
  オフライン録画のままAの11種を量産できます。一致しなければオンライン（フレンド戦）での録画に切り替えます

## 優先度の目安（2026-08-31更新）

1. **0.5（対照録画）** — 2分。Aを量産できるかどうかがこれで決まる
2. **B/C/D（コート・キャラ）** — **パイロットで形式一致が実証済みなので今すぐ量産できます**
   （VS画面/勝敗パネルはランクマ由来の辞書とそのまま一致した）
3. **A（ラケット）** — 認識精度への効果は最大（ハテナ判定・side帰属が上がる）だが 0.5 の結果待ち

※ ベビィピーチはパイロットで収穫済み。収穫前は勝敗パネルで「ピーチ」に0.866で
  **無警告のまま化けていた**（しきい値0.8超え）。同種の取り違えを消せるのがC/Dの効果です
