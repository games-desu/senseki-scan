# 辞書収穫用の録画チェックリスト（2026-08-30版）

ランクマッチ以外（フレンド戦・COM戦等）で辞書の未収穫を埋めるための録画リスト。
**録画設定はいつも通り（1080p・60fps・6〜12Mbps・OBS元録画）**。複数試合を1本にまとめてOK。
撮れたら samples/ に入れて「収穫用」と伝えてください。ラベルは映像から目視確定するので、
**SENSEKI FEVERへの登録は不要**です。

## 0. 最初にパイロット1本（5分でOK）

- [ ] シングルス1試合を最後まで（勝敗パネルが映るところまで）＋任意の未収穫ラケットで発動1〜2回
- → これで「ランクマと同じ表示形式か」を先に確認します。OKなら残りを量産

## A. ラケット 11種（フィーバーシングルス・コート任意）

装備して**発動2回以上**（できれば通常発動とMAX発動の両方＝バナー2種類）。
発動さえ録れれば**試合は途中でやめてOK**。

- [ ] ドッスンラケット ※前回は全発動が画面端で見切れて収穫失敗→**2〜3回発動**推奨

## C. キャラ・シングルス（**試合を最後まで**＝勝敗パネルが必要）

シングルス完走でVSアイコンと勝敗パネルアイコンが同時に埋まります。
**相手側（COM/2P）にも下のキャラを選べば1試合で2キャラ消化**できます。
以下39種（チェックは1キャラ=1個。どちら側で使ってもOK）:

- [ ] カメック / - [ ] ディディーコング / - [ ] ワンワン / - [ ] ボスパックン / - [ ] ほねクッパ
- [ ] トッテン / - [ ] ベビィマリオ / - [ ] ベビィルイージ / - [ ] ベビィピーチ
- [ ] チコ（基本/緑/赤/青/オレンジ/黒/水色 の7色）
- [ ] ヨッシー（基本/青/水色/ピンク/赤/黄 の6色）
- [ ] ヘイホー（基本/青/緑/水色/オレンジ/ピンク/黄 の7色）

※色違いは出現頻度が低いので、面倒なら基本色+よく見る色だけでも十分効果があります

## D. キャラ・ダブルス（**VS画面が映れば即終了でOK**・勝敗パネル不要）

ダブルスのVSカードには4キャラ載るので、**9回のVS表示で全35種**消化できます。
できれば同じキャラを自分チーム側/相手側の両方で1回ずつ（カード背景色が青/オレンジで違うため）。
片側だけでも可。

## 優先度の目安

1. **A（ラケット）** — 認識精度への効果が最大（ハテナ判定・side帰属の精度が上がる）
2. **B（コート）** — 2種だけですぐ終わる
3. **C/D（キャラ）** — フラグ運用でも困らないので余裕のあるときに。色違いは後回しでOK
