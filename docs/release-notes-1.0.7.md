# SENSEKI SCAN v1.0.7 リリースノート（詳細版）

2026-09-08。ユーザー提供のフィーバーダブルス実戦録画（ランクマ・フォレストコート・2試合）で初めて検証し、見つかった3つの問題を直した。

## 症状（v1.0.6 まで）

フィーバーダブルスの録画を読み込むと、試合自体は検出されるが

- ラケットの欄が **4つとも空**（自分・味方・相手1・相手2）
- 試合によって**スコアと勝敗が空欄**（ログに「再探索でも勝敗画面が見つかりませんでした」）
- 回線品質が試合によって読めたり読めなかったりする

## 原因と修正

### 1. ラケット解析がフィーバーシングルス限定だった

ラケット解析（発動バナーの照合＋FVゲージで発動者を決める処理）が `fever_singles` のときだけ動くようになっていた。

フィーバーダブルスのHUDは**4人ぶんのHP/FVゲージ**（左上に自チーム2行・右上に相手チーム2行）を持つ。上の行はシングルスと同じ座標で、
下の行はちょうど108px下にある。この4本のゲージを個別に追跡し、バナーが出た直前に空になったゲージの持ち主を発動者とする。
これで「自分／味方／相手1／相手2」の4人ぶんのラケットが読める（CSVの partner_racket1 / opponent2_racket1 にも入る）。

同じ人から3種類以上のバナーが出たらハテナラケット、という規則もそのまま効く。

「自分の行（上／下）」を後から選び直したときは、自分と味方のラケットも入れ替わる（動画の読み直しは不要）。

### 2. 勝敗パネルを「バナーが重なっている」として捨てていた

勝敗パネルの黄色い勝者枠を探すとき、サンボショットのような**黄色いリボンのバナー**がパネルに重なると誤読するため、バナーが重なっているフレームは捨てる仕組みがある。
このガードが、パネルの下を横切る**コートの白線**をバナーと誤認し、パネルが表示されている1.5秒のうちほとんどのフレームを捨てていた。

黄色を持ち込むのは文字ではなくリボン（文字の真下）なので、重なりの判定をリボンの帯で行うように変えた。白線の「文字箱」はスコアの数字より下にあるため、もう捨てられない。

### 3. 回線アイコンは「自分の行」の横に出る

フィーバーダブルスでは、回線アイコン（4本バー）がHUDの**自分の行**の右に出る。従来は上の行の位置しか見ていなかったので、自分が下の行の試合は回線が読めなかった。
上下どちらも見るようにし、あわせて**どちらの行で読めたかを「自分の行」の判定に使う**。

これまで「自分の名前」を覚えていない初回のダブルスは、確認画面で上／下を選ぶ必要があった。フィーバーダブルスなら回線アイコンの位置で自動的に決まり、
そのとき名前も覚えるので、次からはクラシックダブルスでも選ばずに済む。

## 検証

- 提供録画（2試合）: 自分ハナチャン（トゲゾー）／味方ロゼッタ（ハテナ）vs マリオ（ドッスン）／ポリーン（ファイア）7-3 win、
  自分ハナチャン（トゲゾー）／味方ノコノコ:黄（バナナ）vs マリオ（ドッスン）／デイジー（スター）2-7 loss。バナー16件のうち照合できた全件が発動者のゲージと一致
- 回帰: フィーバーシングルス／クラシックダブルスの手持ち録画は従来と同じ結果
