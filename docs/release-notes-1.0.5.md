# v1.0.5（2026-09-07）

https://github.com/games-desu/senseki-scan/releases/tag/v1.0.5

## 修正
- **一部の試合が丸ごと検出されない件**（利用者フィードバック）
  - VS画面で自分と相手の**両方**が体の大きいキャラ（ブンブン、ドンキーコング、クッパなど）だと、
    キャラのアイコンが左右のカードを塗りつぶしてしまい、VS画面と認識できずにその試合だけ結果から抜け落ちていた
  - VS画面を見分けるときに見ているカードの範囲が、実際のカードより少し下にずれていたのが原因
    （カードの上のほうに残っている色を見られていなかった）。範囲をカードの実寸に合わせ直した
  - 手持ちの録画9本と利用者の録画2本、合わせて5,185フレームで修正前後を突き合わせ、
    変化したのは取り逃していたVS画面だけ（他の判定は一切変わらず）

## 補足
- この症状が出た試合は、これまでも解析ログに
  「◯◯秒のレート画面がどの試合にも紐づきません」という警告が出ていました。
  結果の試合数が合わないときは、この警告と該当区間の録画を送っていただけると原因を特定できます
