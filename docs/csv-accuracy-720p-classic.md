## 判明した原因（すべて実測・再現ツールは tools/ に追加済み）

### 1. VS画面の取り逃し → 試合が丸ごと消える（最重大）
ドンキーコング戦のVS画面で、DKアイコン（茶色）が相手カードを覆い、
オレンジ画素率が **0.043**（閾値0.10・他7試合は0.19〜0.37）となり classify が 'vs' を返さなかった。
→ その試合の rating がひとつ前の試合に吸われず**孤児化して無視**され、試合ごと消えた。

**検証済みの修正**: 黒い名前帯を補助条件に加える。
`orange>0.10 || (orange>0.02 && 黒帯L>0.45 && 黒帯R>0.28)`（blue/white条件は現行のまま）
→ 4動画（720p×2・1080p×2）で**偽陽性ゼロのまま**DK戦を回収。長い相手名（ゆうしゃすらおーん）が
黒帯を白文字で薄めるため右帯の閾値は0.28が下限。

### 2. 警告のオフバイワン → 取り逃しが不可視
`ratingCount > grouped + 1` は「ちょうど1試合欠け」（rating 8 / grouped 7）で発火しない。
**修正案**: どの試合にも紐づかなかった**孤児 rating の存在**を直接警告する（誤報なしで確実に検知できる）。

### 3. コート誤認 6/7 — textVec の暗チャンネルが背景に支配される
32x8 の白グリフ形状は**ほぼ完全一致**しているのに、背景（夜空/観客席/青空）の暗画素の食い違いが
NCC を決めていた。ギャラクシーコートは辞書テンプレ有りなのに 0.41、
「背景が同じく暗い」スタジアム グラスが 0.75 で勝つ。グラス→ハードは 0.87-0.91 で**フラグも立たない**。

**検証済みの修正**: コート照合を**白チャンネルのみのNCC**にする。
→ 今回8フレームで 1/8 → **8/8**（ギャラクシー 0.99 vs 2位 0.62）。
→ 旧3動画のVS 10フレームは全部正解を維持（≥0.97）。リグレッションなし。

### 4. 相手アイコンの辞書が青カード側に偏っている
iconVec は 16x16 の生RGBで**カード背景色が特徴の約4割**を占める。
ハナチャンのテンプレ15枚は全部自分側（青カード）由来のため、ミラー戦の相手側（オレンジカード）
ハナチャンが 0.715 未満に沈み、ノコノコ(0.825)が勝って**無警告誤り**になった。
チコ（Ver.1.1追加キャラ）は辞書に無く、チコ:赤 → ノコノコ:赤(0.697・フラグ付き)。

**対処**: 相手側（オレンジ）からの収穫を辞書に追加する（この動画の t=461.5 に相手側ハナチャン、
t=2391.5 に チコ:赤 の実例あり）。恒久策はミラー戦時の「レート増減で確定」ロジックが既にあるので、
アイコン照合を背景抑制型にするのは次段でよい。

### 5. レート連鎖補完が取り逃しと共鳴して誤値を確定する
m5 の rating前は**正しく3383と読めていた**のに、直前試合（=取り逃したDK戦）が存在しないため
「前試合のafter(3401)と不一致」→ 3401 で上書きされた。取り逃しの二次被害。
修正1で試合が復活すれば自然解消するが、連鎖検証が「読めた値を上書きする」方向に働く点は要注意。

### 6. 720p の数字読み（すべてフラグ付きで検知できていた）
- 最終スコア 4→6 誤読（m7・conf低でフラグ）
- レート末尾1桁 3392→3393（m6・フラグ）
- 初戦のレート前 3352→3355（カウントアップ演出中の読み・unstableでフラグ）
