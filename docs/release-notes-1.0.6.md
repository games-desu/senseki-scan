# SENSEKI SCAN v1.0.6 リリースノート（詳細版）

2026-09-08。ネヤさん（X @neya700）の報告「v1.0.5 でダブルスの設定がうまくできなくなってそう（キャラ選択）／相手の名前とキャラを入れる欄がおかしい」への対応。

## 症状

ダブルスの試合なのに、確認画面が**シングルスの欄立て**（自分キャラ・相手1キャラ・相手1の名前だけ）で出る。

- 自分キャラ／相手1キャラの証拠画像には**2人ぶん**のアイコンが写り、名前は片方とも同じキャラ名（例: 両方「ゲッソー」）になる
- 部門(mode)は `classic_doubles` と正しく出ている＝**部門だけダブルス・欄はシングルス**という食い違い
- 同キャラ扱いになるため勝敗はミラー戦として処理され、result も要確認になる

## 原因

VS画面がダブルスかどうかを `detectDoublesVs`（vision.js）が**カードの色**で判定していた。

```
青 = 左アイコン枠の上30行(x690-808,y852-882) > 0.20
橙 = 右アイコン枠の上30行(x1125-1243,y852-882) > 0.15
黒 = 左の名前帯(x300-620,y852-882) > 0.50
```

パックンフラワーやゲッソーのような**大きいアイコンはカードをほぼ覆い隠す**ため、青／橙が 0.000 まで落ちて判定が不成立になる。
判定が外れるとシングルスの読み取り位置（1人ぶんのカード想定）でキャラも名前も読むため、**両側とも同じキャラに化ける**。

v1.0.3（自分側の青が消える）・v1.0.5（左右とも消えてVS自体を取り逃す）と同じ「巨体キャラがカードを覆う」系統の残りの1か所で、
ダブルス判定だけが色依存のまま残っていた。v1.0.5 で新たに壊れたわけではなく、その組み合わせに当たると以前から起きる。

## 修正

**1. 部門ボードを先に読む（本命・キャラに依存しない）— index.html**

レートパネルの部門ボード（シングルス／ダブルス）は文字テンプレ照合で、キャラの見た目とは無関係。
`groupMatches` はレートパネルが揃った試合だけを返すので、どの試合でも必ず読める。
VS画面の解析に入る前にボードを読み、確信がある（score>0.85）ときは**ボードの結果を優先**する。
見た目の判定と食い違ったときは解析ログに1行残す（`VS画面はシングルスに見えますが部門ボードはダブルスです。ボードを優先します`）。

ボードが読めないときは、これまでどおり見た目の判定を使う。あわせて `m.mode` も、ボードが読めないときは
見た目の判定に合わせるようにした（従来は既定でダブルスになり、今回のような食い違った状態のまま出ていた）。

**2. 見た目の判定を強化（保険）— vision.js `detectDoublesVs`**

アイコンに覆われない**名前欄の黒帯**で救う。ダブルスは上の行（y852-882）に左右とも名前帯があり、シングルスにはそこにカードが無い。

```
従来の色条件が成立 → ダブルス
そうでなくても: 左帯>0.65 かつ 右帯>0.65 かつ（左帯−左外側>0.3 または 右帯−右外側>0.3）→ ダブルス
```

外側（x120-265 / x1660-1800 の背景）との差を見るのは「暗いコートだから帯も暗いだけ」を弾くため。
片側だけの差で判定するのは、左に暗い構造物があるコートで左の差が 0.365 まで縮む実例があったため。

## 実測と検証

- **指標の分離**（VS画面15枚・`samples/frames/dbl-probe-0908.js`）: 名前帯はダブルス 左0.915〜0.985／右0.918〜0.962、
  シングルス 左0.000〜0.246／右0.000〜0.204。外側との差はダブルスで最大側が 0.52〜0.96
- **模擬再現**: ダブルスVSのアイコン枠（x663-815 / x1118-1270・上下2行ぶん）を不透明色で塗って「巨体キャラがカードを覆った」状態を作ると、
  旧判定は7枚すべてシングルス誤判定、新判定は**7枚すべてダブルスに復帰**。シングルス8枚は塗っても誤検出0
- **エンドツーエンド**（`tools/headless-analyze.js`）:
  - ダブルス 14-52-01 = **5試合・キャラ20体・レート連鎖 2613→2594→2580→2602→2605→2611** ＝ v1.0.4/1.0.5 と同一
  - シングルス 15-18-15 = **4試合**（クッパ vs マリオ:オーバーオール 1-7 ほか）＝ v1.0.5 と同一
  - `detectDoublesVs` が必ず false を返すよう一時改造して 14-52-01 を再解析＝**利用者の状況の再現**。
    部門ボード優先の経路だけで **5試合とも従来とまったく同じCSV**（キャラ20体・スコア・コート・レート連鎖まで一致）。全試合に「VS画面はシングルスに見えますが部門ボードはダブルスです」のログが出た
