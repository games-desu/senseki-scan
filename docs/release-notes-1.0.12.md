# SENSEKI SCAN v1.0.12 リリースノート（詳細版）

2026-09-22。v1.0.11 で英語版のゲーム画面から試合を読めるようになったのに続き、アプリの画面そのものを英語で表示できるようにした
（米国の利用者 AuntStarr さんが翻訳ソフト越しに使っていた件）。読み取り結果・CSV の中身は変えていない。

## 使い方

- Windows の言語が日本語以外なら、初回から英語で表示される。右上の **English／日本語** ボタンでいつでも切り替えられ、選んだ言語は設定に保存される
- 英語表示では、確認画面のキャラ名・コート名・ラケット名・部門（Classic Singles 等）が英語で出る。プルダウンも英語。
  手で直すときは英語名でも日本語名でも受け付ける（"Yoshi (Orange)" / "ヨッシー:オレンジ" のどちらでも）
- **CSV の値は従来どおり日本語の正準値**（SENSEKI FEVER の一括登録がそのまま使えるように）。画面の表示だけが英語になる
- 解析ログの警告・注意、ハイライト生成の画面、更新ダイアログ、保存ダイアログの題名も英語になる。ハイライトの書き出しファイル名も
  `_match1_…_me.mp4` のように英語になる（日本語表示のときは従来どおり `_試合1_…_自分.mp4`）

## 仕組み（開発メモ）

- `app/renderer/i18n.js`（新規）: 日本語の文そのものを辞書のキーにする gettext 方式。コードは `t('日本語', 差し込み…)` と書き、
  日本語モードではキーがそのまま出るので**日本語の表示は一字一句変わらない**。英語モードだけ辞書を引く
- 静的な HTML は `applyDom()` が起動直後にテキストノード単位で置き換える。`<b>` を挟む長い段落は要素の innerHTML 単位（語順が変わるため）。
  元の日本語は控えてあるので切替で戻せる
- 固有名は `disp(kind, 正準値)` で表示用の英語名に、入力は `canon(kind, 入力)` で正準値に戻す。対応表は SENSEKI FEVER の
  characters / courts / rackets の name_en と同じ（2026-09-22 取得）。色違いは "Yoshi (Orange)" の形
- 言語の決定: `settings.lang` → 無ければ OS の言語（`navigator.language` が ja 以外なら英語）。ちらつき防止に `localStorage.sc_lang` にも写す。
  main プロセスのダイアログは `settings.json` の lang（無ければ `app.getLocale()`）
- 回帰: 日本語モードで 15-18-15（クラシックシングルス4試合）／22-45-12（フィーバーダブルス2試合）／英語録画2本の CSV・要確認・警告ログが
  v1.0.11 と完全一致。英語モードでも CSV は同一。`tools/headless-analyze.js` / `headless-eval.js` に `--lang en` を追加（既定は日本語に固定）
- `tools/chain-test.js` は抽出したループ内の `t()` を素通しにして従来どおり通る

## 未対応

- 英語版ゲーム画面の辞書は引き続き クラシックシングルス のみ（Doubles / With Fever Rackets / コート14種は録画待ち・v1.0.11 のノート参照）
- 使い方ガイド（manual.md）と GitHub Release の本文は日本語のまま（更新ダイアログの箇条書きは日英併記にした）
