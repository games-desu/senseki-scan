# SENSEKI SCAN 利用マニュアル

マリオテニスフィーバーの対戦録画（MP4）から対戦情報を自動で読み取り、
[SENSEKI FEVER](https://mario-tennis-records.vercel.app/) の「CSV一括登録」にそのまま読み込める
CSVを作る Windows 用アプリです。**解析はすべてお使いのPC内で完結し、動画がどこかにアップロードされることはありません。**

## 動作環境

- Windows 10 / 11（64bit）
- 対応部門: クラシックシングルス / クラシックダブルス / フィーバーシングルス / フィーバーダブルス（自動識別）

## インストール

1. [Releases ページ](https://github.com/games-desu/senseki-scan/releases/latest) から
   `SENSEKI-SCAN-Setup-<バージョン>.exe` をダウンロード
2. **ダウンロード時にブラウザの警告が出ることがあります**（「〇〇は一般的にダウンロードされていません」等）。
   - Edge: ダウンロード一覧でファイルにマウスを乗せる → 「…」メニュー → **「保持する」** → 「詳細表示」→ **「保持する」**
   - Chrome: ダウンロードバーの「…」→ **「継続」（保存）**
3. 実行するとWindowsの「WindowsによってPCが保護されました」（SmartScreen）が出ることがあります。
   **「詳細情報」→「実行」**で進めてください
   - どちらも新しく公開されたアプリに表示される確認画面です。SENSEKI SCAN は安心してご利用ください
     （解析はすべてPC内で完結し、対戦データや動画が外部へ送信されることはありません）
4. インストール先を選んで完了

新しいバージョンが公開されると、アプリ起動時にお知らせが表示されます。更新内容を確認して
**「今すぐ更新」「あとで」「このバージョンをスキップ」**から選べます。


アンインストールはWindowsの「アプリと機能」からいつでもできます。

## 録画のしかた（ここが精度を決めます）

- **OBS等で録画した元ファイルをそのまま使う**こと。編集ソフトで書き出し直した動画は
  画質劣化やカットで読み取りに失敗する実例があります
- 推奨設定: **解像度 1080p以上・フレームレート 30fps以上・ビットレート 6〜12Mbps**（高すぎるビットレート(50Mbps級)でも解析できますが、解析時間が長くなります）
  （1080p/1440pで実証済み。720pでも動きますが精度が落ちます）
- 試合の前後（対戦カード画面〜リザルト・レート画面）が映っている必要があります。
  1本の録画に複数試合入っていてOK・録画の途中から始まった試合も検出します

## 使い方

1. **録画ファイルをドラッグ&ドロップ**（複数まとめてOK。クリックして選択でも可）
2. **解析を待つ**（動画1本あたり数分。録画時間・試合数で前後します）
3. **「1件ずつ確認」で内容をチェック**
   - 証拠画像（実際の画面の切り抜き）と読み取り結果が並んで表示されます
   - **赤枠＝要確認**。画像と見比べて直してください（プルダウンはかな入力で絞り込めます）
   - Enter または → で次の試合へ、← で前へ。上部の進捗ドット（赤=要確認あり）でジャンプもできます
   - **手で直した内容は次回から自動で学習されます**（使うほど賢くなります）
4. **「CSVを保存」→ SENSEKI FEVER の「CSV一括登録」へ読み込み**

## ハイライト生成（得点シーンの切り抜き・v0.4.0〜）

録画から得点シーンを自動で見つけて MP4 に切り出します。X などに投稿する用途を想定しています。

1. 「ハイライト生成」パネルの **「録画を選ぶ…」**（戦績CSVで解析した直後なら「直近の録画で作る」）
2. 試合ごとにポイントが並びます。既定では **自分の得点だけ**にチェックが入っています
3. 気になるポイントは **サムネイルか「区間を調整」** で始点・終点を直せます（ハンドルのドラッグ／区間再生／「開始をここに」）
4. 保存ボタン
   - **得点前の数秒を保存** … 各ポイントの得点確定直前 N 秒（既定5秒）を1本ずつ
   - **ダイジェストを保存** … 上のクリップを試合ごとに1本につないだもの
   - **ラリー全体を保存** … サーブ構えから得点確定までを1本ずつ

- **プレイヤー名は映りません。** ポイント間に出るスコアバナー（名前入り）・VS画面・勝敗画面は自動で除外します。
  手で区間を延ばして名前が映る位置に終点を置いても、「名前が映る区間を自動で除外」がONなら書き出し時に手前へ詰めます
- 「ゲーム画面の位置」を指定してある録画は、その範囲だけを切り出します（配信レイアウトの枠やチャットは入りません）
- 1440p以上の録画は既定で1080pに縮小します（チェックで切替）
- 切り出しは再エンコードなので画質はほぼ元のまま、5秒のクリップで数秒かかります

## よくある質問

**Q. ハイライトの得点シーンが見つからない／少ない**
得点HUD（画面下の数字とテニスボールのピップ）から切れ目を取っています。ゲームが画面いっぱいに映っていない録画は
先に「ゲーム画面の位置」を指定してください。デュースの試合も対応しています。取りこぼしがあれば録画を添えて連絡してください。


**Q. 読み取りが間違っている/空欄がある**
赤枠（要確認）が付いている項目は自信がない読み取りです。確認画面で直してから保存してください。
直した内容は学習され、同じ間違いは減っていきます。

**Q. フィーバーのラケットが「?」のまま**
ラケットは試合中の発動バナー（「〇〇ショット/ブースト」）から読み取ります。
その試合で一度も発動しなかった場合は原理的に読み取れないため、手で入力してください。

**Q. 相手の名前も入れたい**
「相手名の自動入力」をONにすると、過去にCSV保存で確定した名前は画像照合で自動入力されます。
初めて当たる相手は手入力が必要です（10文字まで）。

**Q. 対応していない画面・誤検出を見つけた**
該当区間の録画を添えて作者まで連絡してください（下記）。

## プライバシー

- 解析・学習データ（ユーザー辞書）はすべてPC内（`%APPDATA%/senseki-capture/`）に保存されます
- 外部に送信されるのは自動アップデートの更新確認（GitHubへのアクセス）のみです
